** TODO [#C] Reviewer: document the pipe-based bash write bypass
:PROPERTIES:
:FILE: agent/reviewer.md
:END:

The ="*": deny= catch-all blocks direct mutation, but OpenCode matches
bash patterns on command prefixes, so a pipe such as =git diff | git apply=
still executes and can write. Accepted as residual risk for now; the same
behaviour exists in the global config.

Fix: revisit if OpenCode gains argument- or pipe-aware matching;
otherwise document the accepted risk in the reviewer prompt.

** TODO [#C] Match bare git/cargo commands in agent bash allow lists
:PROPERTIES:
:FILE: agent/orchestrator.md
:END:

Patterns like ="git diff *"= only match commands with arguments; a bare
=git diff= falls through to the global bash default. Harmless while the
global default is ="*": allow=, but would prompt if that default
tightens. =reviewer.md= already carries the bare forms.

Fix: add bare forms (=git diff=, =git log=, =git status=, =cargo check=,
...) alongside the wildcard patterns in =orchestrator.md= and
=rust-dev.md=.
